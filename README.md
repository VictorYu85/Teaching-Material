# Teaching Material

Educational templates, patterns, and agent skills for interactive technical and financial teaching.

## Skills Included

### [`inline-collapsible-definitions`](.agents/skills/inline-collapsible-definitions/SKILL.md)
A design pattern and agent skill for embedding tactile monospace keycap definitions into paragraphs without causing awkward browser line breaks.

- **Non-Breaking Flow**: Avoids browser `<details>` line-break bugs by using native inline tags.
- **Monospace Keycap**: Clean, executive keyboard-style button with depth and active state indicators.
- **Floating Popovers**: Definitions float cleanly above the term without moving surrounding text.

- Open [`examples/index.html`](examples/index.html) in your browser to view a live demonstration featuring **Cash Flow** and **Cap Rate** definitions embedded directly inside an underwriting summary.
